# 🌍 Wandora – Explore. Experience. Remember.

Wandora is a responsive travel discovery website inspired by TripAdvisor, designed to help users explore exciting destinations, adventure activities, hotels, restaurants, and unforgettable travel experiences.

The project focuses on building a modern, visually appealing, and fully responsive front-end using only HTML5 and CSS3 while following clean code practices and intuitive user interface design.

## ✨ Features

- 🔍 Search destinations with a modern search interface
- ⭐ Filter experiences by Rating
- 💰 Filter experiences by Price Range
- 🏨 Browse Hotels and Restaurants
- 🎯 Discover adventure activities
- 🌊 Outdoor, Water & Aerial experiences
- 🏆 Travellers' Choice Award section
- 📍 Explore iconic destinations around the world
- 💖 Donation campaign section
- 📱 Fully Responsive Design
- 🎨 Modern UI inspired by TripAdvisor

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Media Queries
- Font Awesome
- Google Fonts
